## Средняя версия (для Habr/VC.ru)

```
# Как я сделал бота для разделения счетов и получил 59 реальных пользователей

Всем привет! Хочу поделиться результатами своего пет-проекта - Telegram бота для автоматического разделения счетов в компании.

## Проблема
Кто из вас терял время на подсчет "кто сколько должен" после похода в ресторан? Я регулярно. Калькулятор, листок бумаги, споры кто что заказывал...

## Решение
Сделал Telegram Mini App с OCR распознаванием чеков:
1. Загружаешь фото чека
2. Google Gemini распознает все позиции
3. Делишься ссылкой с друзьями
4. Каждый выбирает свои блюда
5. Приложение автоматически считает доли

## Результаты за первый месяц
📊 **59 пользователей** - реальные люди, не друзья/знакомые  
📄 **51 чек** на общую сумму **726 749 ₽**  
💰 **Средний чек:** 14 250 ₽  
🏆 **Рекорд:** чек на 312 400 ₽ в ресторане PLATAN  
👥 **Самая большая компания:** 8 человек в баре "Фабула"

## Технологии
- Backend: Node.js + Express
- Database: Supabase (PostgreSQL)
- Frontend: React + TypeScript
- OCR: Google Gemini API
- Hosting: Yandex Object Storage + Timeweb Cloud

## Интересные детали
1. **Проблема с блокировками:** Supabase блокируется у некоторых провайдеров → решил через прокси-сервер на Timeweb (Нидерланды)
2. **OCR качество:** Изначально использовал Tesseract, точность 60% → переключился на Gemini, стало 95%+
3. **UX:** Добавил подтверждение качества фото перед распознаванием - снизилось количество повторных загрузок

## Что дальше

- Экспорт в PDF

- API для интеграции в POS-системы ресторанов

Попробовать: @SplitterReceipt_bot
GitHub: https://github.com/KonyashinAleksey/receipt-splitter-setup

Буду рад фидбеку и вопросам! 🚀
```
